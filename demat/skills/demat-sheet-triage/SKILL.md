# DEMAT sheet triage

Read the page image at the path given in the prompt. Determine:

1. Whether this is a DEMAT score sheet at all (`is_demat_sheet`).
2. If so, which version — look for one of the known versions below printed
   on the sheet (usually in the header or footer), plus any
   version-identifying cues (subtest names, layout). If a sheet prints
   something that isn't in this list (e.g. "DEMAT 4+", which does not
   exist), treat the version as not determinable (`null`) rather than
   guessing; it routes to the generic extraction skill and gets flagged for
   review.
3. The printed test form letter, if visible (e.g. "Form A").

<!-- KNOWN_VERSIONS:START (generated by scripts/sync_skills.py from demat/test_definitions/*.toml — do not edit by hand) -->
- DEMAT 1+
- DEMAT 2+
- DEMAT 3+
- DEMAT 5+
<!-- KNOWN_VERSIONS:END -->

Do not attempt full transcription here — that is a separate skill's job.

Read `reference.md` in this directory before writing the output (it covers
the shared confidence conventions and the exact JSON shape for this skill).

## Output contract

Write exactly one JSON object to the `output_path` given in the prompt:

```json
{
  "is_demat_sheet": true,
  "test_version": "DEMAT 2+",
  "test_form": "A",
  "confidence": "high",
  "notes": null
}
```

`test_version` and `test_form` are `null` if not determinable.
`is_demat_sheet: false` for anything that clearly isn't a DEMAT sheet (blank
page, unrelated document, etc.) — set `test_version`/`test_form` to `null`
and put a short reason in `notes`.
